# Linux Command Line Training 

Learn the Linux command line on the night shift at Neon Harbor Dispatch. Guided lessons teach the tools, and dispatch puzzles let you put them to work.

**Download [lab.sh](lab.sh)** to a Linux machine. From the directory where you saved it, run

```bash
bash lab.sh
```

Choose **Start guided training** to start the first lesson. The course is bundled in that one file.
